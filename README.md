How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Ensure index.html, style.css, and script.js are in the same folder.
4. Add your profile photograph and name it profile.jpg.
5. Open index.html in your web browser.
6. Alternatively, use the Live Server extension in Visual Studio Code.

Important: If your photo has a different filename, update the image filename in index.html.
